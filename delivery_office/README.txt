موقع وصّلني للتوصيل
====================

طريقة التشغيل:
1. فك ضغط الملف.
2. افتح مجلد delivery-office.
3. افتح ملف index.html بواسطة Google Chrome أو أي متصفح.
4. للتعديل استخدم Notepad++ وافتح:
   - index.html للمحتوى
   - style.css للألوان والتصميم
   - script.js للوظائف

ملاحظة:
الموقع يعمل بدون قاعدة بيانات. نموذج الطلب وتتبع الشحنة وحاسبة السعر تجريبية.
يمكن لاحقاً ربطها بقاعدة بيانات PHP/MySQL وإضافة تسجيل دخول ولوحة تحكم.
